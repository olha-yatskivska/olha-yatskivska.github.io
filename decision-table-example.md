## Tricky Decision Table Terms

> Sources:
> * Course ISTQB Advanced Test Analyst from the [Trainer Alexandra Kovalova](https://certifiedunicorns.pro/advancedistqb?utm_source=telegram&utm_medium=webinar-agile-anons&utm_campaign=25-05)


1. **Limited-entry decision tables**: The most common type of DT where conditions are just True/False or Yes/No. [Tax-system-example](./dt-tax-system-example.md)

2. **Full decision table**: A DT where number of rules is calculated by multipling all the parameters  [Bicycle-rental-srm-example](./dt-bicycle-rental-srm-example.md)

3. **Collapsed decision table**: A DT where rules that have the same outcome for the same reason are combined [Good-health-example](./dt-good-health-example.md) 

4. **Infeasible combinations/Not applicable conditions**: A DT where some conditions are not applicable depending on the parameters of other conditions (N/A) [Credit-account-worked-example](./dt-credit-account-worked-example.md) 

5. **"Don’t care" values:** A DT where a parameter can be any value and it will still lead to the same action  (~) [Online-shopping-cart-example](./dt-online-shopping-cart-example.md) 

6. **Extended-entry decision tables:** A DT where parameters for conditions are not only binary values. [Train-ticket-example](./dt-train-ticket-example.md)
